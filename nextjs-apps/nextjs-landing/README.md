# NextJS Landing Page Template

A modern, dark-themed landing page template built with Next.js 15, TypeScript, and Tailwind CSS.

## Features

- Hero section with gradient text and CTA buttons
- Features grid showcasing key benefits
- Pricing section with three tiers
- Customer testimonials with ratings
- Contact form with validation
- Responsive dark theme design
- Modern component architecture

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Theme:** Dark mode

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
