# React Weather

A weather app using the Open-Meteo API with geocoding support.

## Features

- City search with autocomplete-style geocoding
- Real-time weather data from Open-Meteo
- Dark theme UI
- Shows temperature, humidity, wind speed, and conditions

## Setup

```bash
cd react-weather
npm install
npm run dev
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Open-Meteo API (free, no API key required)
