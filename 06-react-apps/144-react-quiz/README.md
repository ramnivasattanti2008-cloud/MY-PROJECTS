# React Quiz App

An interactive quiz application with multiple choice questions, score tracking, and detailed explanations.

## Features

- 10 general knowledge questions
- Multiple choice answers (A, B, C, D)
- 15-second timer per question
- Score tracking
- Detailed explanations after each answer
- Visual feedback for correct/incorrect answers
- Results screen with percentage score
- Answer review with colored dots

## Quiz Topics

Questions cover various topics including:
- Geography (capitals, countries)
- Science (planets, elements, mammals)
- History (World War events)
- Art (famous paintings)
- General knowledge

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## How to Play

1. Click "Start Quiz" to begin
2. Answer each question before the 15-second timer runs out
3. View the explanation for each answer
4. Click "Next Question" to continue
5. See your final score and review your answers

## Scoring

- Correct answers: 1 point each
- Maximum score: 10 points
- No negative marking

## Tech Stack

- React 18
- TypeScript
- Vite
