# Random Quote Generator

A beautiful, dark-themed random quote generator built with React and TypeScript.

## Features

- Fetches random quotes from the Quotable API
- Fallback quotes when API is unavailable
- Share button (uses Web Share API on mobile)
- Copy to clipboard functionality
- Loading spinner
- Dark theme UI
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## API

Uses the free [Quotable API](https://github.com/lukePeavey/quotable) to fetch random inspirational quotes.

## Tech Stack

- React 18
- TypeScript
- Vite
- Quotable API
- CSS-in-JS (inline styles)
