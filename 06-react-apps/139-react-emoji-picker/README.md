# React Emoji Picker

A sleek, dark-themed emoji picker component built with React and TypeScript.

## Features

- 8 emoji categories: Smileys, People, Animals, Food, Activities, Travel, Objects, Symbols
- Category navigation tabs
- Search functionality
- Click-to-copy with visual feedback
- Dark theme UI
- Responsive grid layout

## Getting Started

```bash
npm install
npm run dev
```

## Usage

The `EmojiPicker` component is exported from `src/EmojiPicker.tsx`.

Click any emoji to copy it to your clipboard.
