# Weather Widget

A sleek, dark-themed weather widget built with React and TypeScript.

## Features

- City search with geocoding
- Real-time weather data from Open-Meteo API
- Temperature display in Celsius
- Weather condition icons and descriptions
- Humidity and wind speed details
- Dark theme UI
- Responsive design
- Loading states and error handling

## Getting Started

```bash
npm install
npm run dev
```

## API

Uses the free [Open-Meteo API](https://open-meteo.com/) for weather data and geocoding. No API key required.

## Tech Stack

- React 18
- TypeScript
- Vite
- Open-Meteo API
- CSS-in-JS (inline styles)
