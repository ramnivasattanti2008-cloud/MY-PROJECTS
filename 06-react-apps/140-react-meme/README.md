# React Meme Generator

Create memes with top and bottom text and download as PNG.

## Features

- 5 classic meme templates
- Add top and bottom text (auto uppercase)
- Live preview with classic Impact font styling
- Download as PNG
- Dark theme UI

## Setup

```bash
cd react-meme
npm install
npm run dev
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Canvas API for rendering and export
