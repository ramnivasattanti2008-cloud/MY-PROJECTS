# Weather App

A beautiful weather application that fetches real-time weather data using the Open-Meteo API (free, no API key required).

## Features

- Search weather by city name
- Real-time weather data using Open-Meteo API
- Displays temperature, humidity, and wind speed
- Weather condition icons and descriptions
- Beautiful gradient UI
- Responsive design

## API

Uses [Open-Meteo](https://open-meteo.com/) free weather API:
- Geocoding API for location search
- Weather API for current conditions

No API key required!

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Weather Codes

The app supports various weather conditions including:
- Clear sky
- Partly cloudy
- Overcast
- Foggy
- Rain/Drizzle
- Snow
- Thunderstorms

## Tech Stack

- React 18
- TypeScript
- Vite
- Open-Meteo API
