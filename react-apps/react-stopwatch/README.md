# React Stopwatch

A sleek, dark-themed stopwatch app built with React and TypeScript.

## Features

- Start/Pause/Resume functionality
- Reset stopwatch to zero
- Lap time recording
- Precision timing (centiseconds)
- Dark theme UI
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Usage

- Click **Start** to begin the timer
- Click **Pause** to pause at any time
- Click **Lap** while running to record lap times
- Click **Reset** to clear and start over

## Tech Stack

- React 18
- TypeScript
- Vite
- CSS-in-JS (inline styles)
