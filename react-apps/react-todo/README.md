# React Todo App

A feature-rich todo application with localStorage persistence, categories, filtering, and dark/light theme support.

## Features

- **CRUD Operations**: Create, read, update, and delete todos
- **Categories**: Work, Personal, Shopping, Health
- **Filtering**: Filter by category or view all
- **Dark/Light Theme**: Toggle between themes
- **LocalStorage**: Todos persist across browser sessions
- **Statistics**: Track completed vs total todos
- **Edit**: Double-click to edit a todo

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Categories

- Work (Blue)
- Personal (Purple)
- Shopping (Orange)
- Health (Green)

## Usage Tips

- Type your todo and select a category, then click Add
- Click the checkbox to mark complete/incomplete
- Double-click on a todo text to edit it
- Click Delete to remove a todo
- Use the filter buttons to show specific categories
- Toggle the theme button in the header

## Tech Stack

- React 18
- TypeScript
- Vite
- localStorage API
