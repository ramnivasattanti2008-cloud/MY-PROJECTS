# React Calculator

A modern calculator app built with React and TypeScript, featuring a sleek dark theme and full keyboard support.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Percentage and sign toggle
- Backspace functionality
- Full keyboard support (numbers, operators, Enter, Escape, Backspace)
- Dark theme UI
- Responsive design

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Input digits |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter / = | Calculate result |
| Escape | Clear all |
| Backspace | Delete last digit |
| % | Percentage |
| . | Decimal point |

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Vite
