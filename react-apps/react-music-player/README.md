# Music Player

A sleek, dark-themed music player built with React and TypeScript.

## Features

- Upload audio files (multiple at once)
- Play/pause controls
- Previous/next track navigation
- Progress bar with seeking
- Volume control
- Playlist management
- Remove tracks from playlist
- Auto-play next track
- Dark theme UI
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Usage

1. Click "Upload Audio Files" to add music from your computer
2. Click any track in the playlist to play it
3. Use the controls to play/pause, skip tracks, or adjust volume
4. Hover over a track and click the X button to remove it

## Tech Stack

- React 18
- TypeScript
- Vite
- HTML5 Audio API
- CSS-in-JS (inline styles)
