# React Timer

A sleek countdown timer built with React.

## Features

- Preset times: 1, 5, 10, 15, 30, 60 minutes
- Browser notifications when timer completes
- Dark theme UI
- Start, pause, and reset controls

## Setup

```bash
cd react-timer
npm install
npm run dev
```

## Tech Stack

- React 18
- TypeScript
- Vite
