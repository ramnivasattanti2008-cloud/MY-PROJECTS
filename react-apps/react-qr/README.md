# React QR Code Generator

Generate QR codes from text or URLs and download as PNG.

## Features

- Real-time QR code generation
- Supports any text or URL
- Download as PNG file
- Dark theme UI
- Transparent background option

## Setup

```bash
cd react-qr
npm install
npm run dev
```

## Tech Stack

- React 18
- TypeScript
- Vite
- qrcode library
