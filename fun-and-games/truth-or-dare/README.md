# Truth or Dare

The ultimate party game experience! Challenge your friends, uncover secrets, and complete hilarious dares.

## Features

- **40+ Truths** - Deep questions to discover secrets
- **40+ Dares** - Fun challenges to complete
- **Hard Mode** - Extreme truths and dares for brave souls
- **Multiple Players** - 2+ players supported
- **Score System** - Earn points for completing challenges
- **Bottle Spinner** - Animated spinning bottle effect
- **Turn Tracking** - Know whose turn it is
- **Final Standings** - Crown the ultimate champion!

## Installation

```bash
# Install colorama for colored output
pip install colorama

# Run the game
python truth-or-dare.py
```

## Usage

```bash
python truth-or-dare.py
```

### Setup

1. Enter player names one at a time
- Type 'done' when all players have joined
- Minimum 2 players required

### Game Flow

1. Bottle spins to select a player
2. Player chooses Truth or Dare
3. Question/challenge appears
4. Player answers/completes
5. Points awarded if successful

### Scoring

| Mode | Success | Failure |
|------|---------|---------|
| Normal | +5 points | -2 points |
| Hard Mode | +10 points | -2 points |

## Menu Options

- `[1]` Truth - Answer honestly
- `[2]` Dare - Complete a challenge
- `[3]` Hard Mode - Extreme version (auto-selected)
