# Fortune Cookie

A fun virtual fortune cookie that reveals random fortunes with a beautiful ASCII art presentation!

## Features

- Random fortune selection from a curated collection
- Beautiful ASCII art fortune cookie
- Multiple fortune categories (wisdom, humor, motivation, love, success)
- Animated reveal effect
- Fun facts after each fortune

## Usage

```bash
python fortune-cookie.py
```

## Fortune Categories

The fortune cookie includes fortunes in these categories:
- **Wisdom**: Philosophical and thought-provoking quotes
- **Humor**: Funny and light-hearted fortunes
- **Motivation**: Inspirational and encouraging messages
- **Love**: Romantic and heartwarming fortunes
- **Success**: Business and career-related wisdom

- Ask a question mentally before opening for a "question-based" fortune
- Try running multiple times to get different fortunes
