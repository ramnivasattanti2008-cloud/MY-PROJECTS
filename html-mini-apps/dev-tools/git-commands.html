Git Commands Cheatsheet

Click any command to copy it to clipboard

Getting Started

git init
Initialize a new Git repository
git clone <url>
Clone a repository
git config --global user.name "Your Name"
Set your username
git config --global user.email "you@email.com"
Set your email

Branching

git branch
List all local branches
git branch <branch-name>
Create a new branch
git checkout <branch>
Switch to a branch
git checkout -b <branch>
Create and switch to new branch
git switch <branch>
Switch branch (modern)
git switch -c <branch>
Create and switch (modern)
git branch -d <branch>
Delete a branch
git merge <branch>
Merge branch into current

Remote Operations

git remote -v
List remote repositories
git remote add origin <url>
Add a remote
git fetch
Download changes from remote
git pull
Fetch and merge changes
git push
Upload local changes
git push -u origin <branch>
Push and set upstream

Stash

git stash
Save working changes temporarily
git stash pop
Apply stash and remove it
git stash apply
Apply stash without removing
git stash list
List all stashes
git stash drop
Remove a stash

Undo Changes

git status
Check repository status
git diff
Show unstaged changes
git diff --staged
Show staged changes
git add .
Stage all changes
git commit -m "message"
Commit staged changes
git reset HEAD <file>
Unstage a file
git checkout -- <file>
Discard local changes
git reset --soft HEAD~1
Undo last commit (keep changes)
git revert HEAD
Create revert commit

Advanced

git log --oneline --graph --all
Visual branch history
git rebase <branch>
Rebase onto another branch
git cherry-pick <commit>
Pick a specific commit
git bisect start
Find buggy commit
git reflog
View all ref updates
git submodule add <url>
Add a submodule
git tag <version>
Create a tag
git push --tags
Push all tags
