# AI LinkedIn Post 💼

Create engaging, viral-worthy LinkedIn posts with AI-powered content generation.

## Features

- **Hook Generator** - Creates attention-grabbing openings
- **Multiple Tones** - Professional, inspirational, educational, and more
- **Hashtag Optimization** - Relevant hashtags for maximum reach
- **Engagement Focus** - Posts designed to drive comments and shares

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your API key:
```bash
export GEMINI_API_KEY="your-api-key"
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Describe your idea, experience, or topic
2. Select tone (Professional, Inspirational, etc.)
3. Choose length (Short, Medium, Long)
4. Select your industry
5. Click "Generate Post"
6. Copy your optimized LinkedIn post

## Post Ideas

- "I just launched my first product"
- "Lessons from 5 years in tech"
- "Why I switched careers"
- "Tips for remote work productivity"
- "My journey to becoming a leader"

## Tips for Viral Posts

| Element | Best Practice |
|---------|---------------|
| Hook | Start with a question, number, or bold statement |
| Timing | Post Tuesday-Thursday, 8-10 AM or 5-6 PM |
| Engagement | Reply to every comment within the first hour |
| Hashtags | Use 3-5 relevant + 1 trending hashtag |

## Tech Stack

- Streamlit - Web UI
- Google Gemini - AI content generation
- Python - Backend logic
