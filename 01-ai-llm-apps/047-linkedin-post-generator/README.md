# LinkedIn Post Generator

Create engaging, viral-worthy LinkedIn posts with AI. Perfect for professionals, entrepreneurs, and thought leaders.

## Features

- AI-powered post generation with Gemini
- Multiple tone options (Professional, Inspirational, Educational, etc.)
- Customizable length (Short, Medium, Long)
- Optional call-to-action
- Emoji support
- Industry-specific content
- Character count display

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your Gemini API key:
```bash
export GEMINI_API_KEY=your_api_key_here
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Enter your post topic or theme
2. Select tone (Professional, Inspirational, etc.)
3. Choose length preference
4. Optionally add industry context
5. Toggle emoji and CTA options
6. Click "Generate Post"

## Post Structure

Each generated post includes:
1. **Hook:** Attention-grabbing first line
2. **Body:** Value-driven content
3. **Key Takeaways:** Bullet points
4. **Call-to-Action:** Engagement prompt
5. **Hashtags:** 3-5 relevant tags

## Tone Options

- **Professional:** Business-appropriate, authoritative
- **Inspirational:** Motivational and uplifting
- **Educational:** Teaching-focused, informative
- **Storytelling:** Narrative-driven, personal
- **Bold:** Challenging assumptions, provocative
