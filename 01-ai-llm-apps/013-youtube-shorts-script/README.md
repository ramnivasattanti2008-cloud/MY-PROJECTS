# 🎬 YouTube Shorts Script Generator

Create engaging YouTube Shorts scripts with hook, body, and CTA sections.

## Features

- Structured script format
- Hook + Body + CTA structure
- Caption overlay ideas
- Thumbnail suggestions
- Multiple script generation

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)

3. Run the app:
```bash
streamlit run app.py
```

4. Enter your API key in the sidebar

## Usage

1. Enter your Shorts topic
2. Select your content style
3. Define your target audience
4. Choose duration and number of scripts
5. Click "Generate Script"

## Script Structure

- **Hook**: First 3 seconds to grab attention
- **Body**: Main engaging content
- **CTA**: Call to action (like, subscribe, comment)
- **Captions**: Text overlay ideas
- **Thumbnail**: Preview ideas

## Tips

- Keep hooks under 3 seconds
- Use trending sounds
- Add text overlays
- Practice before recording

## Tech Stack

- Streamlit
