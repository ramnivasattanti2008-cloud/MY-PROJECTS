# 🐦 AI Tweet Generator

Generate engaging, AI-powered tweets with hashtag suggestions.

## Features

- Generate 1-5 tweets per request
- Choose from 5 different tones
- Automatic hashtag suggestions
- Clean, modern dark UI

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)

3. Run the app:
```bash
streamlit run app.py
```

4. Enter your API key in the sidebar

## Usage

1. Enter your topic (e.g., "AI in healthcare", "Startup tips")
2. Select your preferred tone
3. Choose number of tweets to generate
4. Click "Generate Tweets"

## Tech Stack

- Streamlit
- Google Gemini AI
- Python
