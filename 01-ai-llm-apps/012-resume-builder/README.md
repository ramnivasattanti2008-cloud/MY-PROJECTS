# 📄 AI Resume Builder

Generate professional, ATS-friendly resume bullet points instantly.

## Features

- Action-verb focused bullet points
- ATS-friendly formatting
- Quantified achievements
- Experience level customization
- Multiple section generation

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)

3. Run the app:
```bash
streamlit run app.py
```

4. Enter your API key in the sidebar

## Usage

1. Enter your target job title
2. Select your experience level
3. List your skills (comma separated)
4. Optionally add key achievements
5. Click "Generate Bullet Points"

## Tips for Great Resumes

- Use strong action verbs
- Quantify your achievements
- Tailor to each job application
- Keep it concise and relevant

## Tech Stack

- Streamlit
- Google Gemini AI
- Python
