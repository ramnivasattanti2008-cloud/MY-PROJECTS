# Jarvis project context

Goal: a free, local "Jarvis" for Ram's Windows laptop that can control the PC and build things, with no usage limits.

## Stack
- Ollama (local LLM server, localhost:11434); model chosen by hardware in `setup.ps1`, saved to `config.json`
- Open Interpreter (`interpreter` package) runs code/controls the PC; wrapped by `jarvis.py`
- `jarvis_voice.py`: offline voice (faster-whisper + Windows System.Speech), wake word "Jarvis"
- Open WebUI in `.venv-webui` for browser chat (chat only)
- Launchers: `Jarvis.bat`, `Jarvis-Voice.bat`, `Jarvis-UI.bat` (generated by `setup.ps1`)

## Constraints / gotchas
- Python 3.11 required (3.13 fails building tiktoken); pin `setuptools<81` for Open Interpreter
- `auto_run` is False by default so every code block needs y/n; `display=False` would skip confirmations, so keep using `chat()` with display on
- Scripts must stay ASCII with CRLF for .bat/.ps1
- setup.ps1 and the voice loop were NOT yet run on the real laptop; first-run errors are expected, fix them
