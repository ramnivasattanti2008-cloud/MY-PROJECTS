# AI Bio Writer

Craft perfect LinkedIn and Twitter bios in seconds with AI. Enter your professional details and get optimized bios that attract attention.

## Features

- AI-generated bios for LinkedIn and Twitter
- Platform-optimized tone and length
- Professional and engaging writing style
- Dark theme with emoji accents

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your Gemini API key:
```bash
export GEMINI_API_KEY=your_api_key_here
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Enter your name and professional title
2. Add your industry and years of experience
3. List your key skills and achievements
4. Select target platform (LinkedIn, Twitter, or Both)
5. Click "Generate Bio"

## Bio Tips

**LinkedIn:**
- Include industry keywords
- Professional tone
- 200 characters max

**Twitter:**
- Catchy and memorable
- Punchy and engaging
- 160 characters max
