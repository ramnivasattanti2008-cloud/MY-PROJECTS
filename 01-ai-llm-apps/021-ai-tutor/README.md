# AI Tutor

An AI-powered study companion that generates personalized lessons with key concepts, examples, and quizzes.

## Features
- Subject & topic-based lesson generation
- Adjustable difficulty levels (Beginner, Intermediate, Advanced)
- Key concepts with clear explanations
- Real-world examples
- Common mistakes to avoid
- Practice quiz questions

## Setup
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_api_key
streamlit run app.py
```

## Usage
1. Enter your Gemini API key in the sidebar
2. Enter subject and topic
3. Select difficulty level
4. Click "Generate Lesson"
