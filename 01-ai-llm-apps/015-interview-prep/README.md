# 💼 AI Interview Prep

Generate AI-powered interview questions and sample answers for any role.

## Features

- Role-specific questions
- Industry-focused content
- STAR method answers
- Multiple interview types
- Red flags to avoid
- Pro tips included

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)

3. Run the app:
```bash
streamlit run app.py
```

4. Enter your API key in the sidebar

## Usage

1. Enter your target job role
2. Select industry and experience level
3. Choose interview types
4. Click "Generate Questions"

## STAR Method

For behavioral questions, use:
- **Situation**: Set the scene
- **Task**: Your responsibility
- **Action**: What you did
- **Result**: Outcome (with metrics if possible)

## Tips

- Practice out loud
- Research the company
- Prepare your own questions
- Dress appropriately
- Send thank you notes
