# MCQ Generator

Generate multiple choice questions instantly for any topic with AI.

## Features

- Input any topic and subject area
- Choose difficulty level (Easy, Medium, Hard)
- Generate 3-15 questions at once
- Option to include answer key with explanations
- Dark theme with polished UI

## Setup

1. Create a `.env` file with your API key:
```
GEMINI_API_KEY=your_api_key_here
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Enter your topic and subject
2. Select difficulty level
3. Choose number of questions
4. Toggle answer key visibility
5. Click "Generate Questions"
6. Get formatted MCQs with options and answers

## Use Cases

- Exam preparation
- Quiz creation
- Educational content
- Training materials
- Interview questions

## Tech Stack

- Streamlit
- Google Gemini AI
- Python dotenv
