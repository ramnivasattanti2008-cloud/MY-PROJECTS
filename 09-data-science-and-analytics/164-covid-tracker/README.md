# COVID-19 Global Tracker

A real-time COVID-19 statistics dashboard built with Streamlit and Plotly.

## Features

- **Country Selector**: Choose from 20 major countries
- **Time Range**: Adjustable from 7 to 90 days
- **Key Metrics**: Total cases, deaths, active cases, mortality rate
- **Interactive Charts**: Line charts, bar charts, pie charts
- **Global Comparison**: Top 10 countries by case count

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Data Source

Data sourced from OpenDataSoft COVID-19 public dataset with hourly updates.
