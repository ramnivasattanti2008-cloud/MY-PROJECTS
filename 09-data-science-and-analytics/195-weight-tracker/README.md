# Weight Tracker - Streamlit App

Track your weight and health metrics with beautiful charts.

## Features

- Log daily weight measurements
- Track weight over time with line charts
- Calculate and display BMI
- Set weight goals
- Visual progress tracking
- Calculate weight loss/gain statistics

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Weight entries are stored in `weight.db` (SQLite).
