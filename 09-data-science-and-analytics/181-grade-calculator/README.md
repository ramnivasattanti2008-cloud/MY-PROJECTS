# Grade Calculator & Analyzer

A comprehensive academic performance tracker with GPA calculation and visualizations.

## Features

- **12 Subjects**: Input marks for various academic subjects
- **Credit Hours**: Weighted GPA calculation based on credit hours
- **Grade Assignment**: Automatic grade calculation from marks
- **GPA Calculation**: Cumulative GPA with quality points
- **Interactive Charts**: Bar charts, pie charts, radar charts
- **Export**: Download your grade sheet as CSV

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
