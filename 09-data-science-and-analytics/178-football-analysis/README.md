# Football Analysis App ⚽

A comprehensive Streamlit application for analyzing football/soccer player statistics with interactive visualizations.

## Features

- **Overview Dashboard**: League statistics, top scorers, playmakers, and best-rated players
- **Player Statistics**: Detailed analysis of individual player performance
- **Player Comparison**: Compare multiple players with radar charts and bar charts
- **Visual Analytics**: Scatter plots, correlation heatmaps, and distribution charts

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```

## Sample Data

The app includes sample data for 15 international football players including:
- Erling Haaland, Kylian Mbappe, Lionel Messi, Cristiano Ronaldo
- Mohamed Salah, Harry Kane, Robert Lewandowski, Kevin De Bruyne
- Vinicius Jr, Jude Bellingham, Phil Foden, Bukayo Saka
- Marcus Rashford, Ousmane Dembele, Jamal Musiala

## Metrics Analyzed

- Goals and assists
- Player ratings
- Pass accuracy
- Dribble success rate
- Shots per game
- Discipline (cards)
- Goal involvement

## Tech Stack

- Streamlit - Web framework
- Pandas - Data manipulation
- Plotly - Interactive visualizations
- NumPy - Numerical computing
