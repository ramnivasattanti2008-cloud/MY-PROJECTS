# Reading List Manager - Streamlit App

Track your reading journey with a beautiful book manager.

## Features

- Add books with title, author, and genre
- Track reading status (To Read, Reading, Completed)
- Rate completed books (1-5 stars)
- Add personal notes to books
- Visualize reading statistics
- Filter by status and genre

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Books are stored in `books.db` (SQLite).
