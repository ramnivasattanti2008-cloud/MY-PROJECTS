# Cricket Analysis App 🏏

A comprehensive Streamlit application for analyzing cricket player statistics with interactive visualizations.

## Features

- **Overview Dashboard**: Quick stats summary and top performers ranking
- **Career Statistics**: Detailed analysis of individual player careers
- **Player Comparison**: Compare multiple players side-by-side with radar charts
- **Performance Charts**: Interactive scatter plots, pie charts, and correlation heatmaps

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```

## Sample Data

The app includes sample data for 12 international cricket players including:
- Virat Kohli, Rohit Sharma, Steve Smith, Kane Williamson
- Joe Root, Babar Azam, David Warner, Ben Stokes
- Chris Gayle, AB de Villiers, Rahul Dravid, Sachin Tendulkar

## Tech Stack

- Streamlit - Web framework
- Pandas - Data manipulation
- Plotly - Interactive visualizations
- NumPy - Numerical computing
