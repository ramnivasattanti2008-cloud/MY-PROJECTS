# Mad Libs Generator

The classic word-filling game brought to life! Create hilarious stories by filling in blanks with funny words.

## Features

- **5 Unique Story Templates** - Space Adventure, Dragon Tale, Superhero Life, Cooking Disaster, Zoo Escape
- **Type-Checked Input** - Each blank has a specific word type (verb, noun, adjective, etc.)
- **Color-Coded Prompts** - Visual feedback for different word types
- **Complete Stories** - Fill all blanks to generate your masterpiece
- **Play All Mode** - Experience every story in one session
- **Random Story Mode** - Let fate choose your adventure

## Installation

```bash
# Install colorama for colored output
pip install colorama

# Run the game
python mad-libs.py
```

## Usage

```bash
python mad-libs.py
```

## Word Types

Each blank has a specific word type for better stories:

| Type | Example | Color |
|------|---------|-------|
| Verb | run, eat, jump | Green |
| Verb ending in -ing | running, eating | Green |
| Adjective | big, silly, purple | Yellow |
| Plural Noun | cats, trees, pizzas | Cyan |
| Animal | dog, elephant, penguin | Magenta |
| Food | pizza, banana, chocolate | Red |
| Place | Paris, school, beach | Blue |
| Name | famous person or any | Light Magenta |
