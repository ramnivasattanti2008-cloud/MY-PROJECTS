# Study Tracker - Streamlit App

Track your study sessions and visualize progress.

## Features

- Log study sessions with subject and duration
- View total hours per subject
- Set weekly study goals
- Progress charts showing study patterns
- Track streaks and consistency

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Study sessions are stored in `study.db` (SQLite).
