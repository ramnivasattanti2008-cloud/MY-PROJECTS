# Personal Budget Tracker - Streamlit App

A dark-themed budget tracking application with charts and savings goals.

## Features

- Add income and expense transactions
- Categorize transactions (Food, Transport, Entertainment, etc.)
- Monthly spending charts
- Set and track savings goals
- Visual breakdown by category

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Transactions are stored in `budget.db` (SQLite).
