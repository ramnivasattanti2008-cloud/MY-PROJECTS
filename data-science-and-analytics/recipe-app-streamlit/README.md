# Recipe Manager - Streamlit App

A clean, dark-themed recipe management application.

## Features

- Add new recipes with name, ingredients, instructions, and cooking time
- Search recipes by name or ingredients
- View recipe details
- Delete recipes
- Visualize cooking times with charts

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Recipes are stored in `recipes.db` (SQLite).
