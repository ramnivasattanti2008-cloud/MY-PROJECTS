# World Population Visualizer

An interactive dashboard to explore global population data.

## Features

- **Top 20 Countries**: Bar chart visualization of most populous nations
- **Continent Distribution**: Pie chart and bar chart breakdowns
- **Country Comparison**: Compare multiple countries side by side
- **Filtering**: Filter by continent and sort options
- **Statistics Table**: Detailed population statistics

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Data Source

World Bank Population Estimates (2023) - embedded dataset covering 50+ countries.
