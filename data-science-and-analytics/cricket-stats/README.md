# Cricket Statistics Dashboard

An interactive dashboard to explore cricket player stats, team rankings, and match data.

## Features

- **Top Players**: 15 international cricketers with detailed stats
- **Player Stats**: Runs, average, strike rate, centuries, half-centuries
- **Team Rankings**: Win percentages for 10 major cricket teams
- **Recent Matches**: Match results with venues and margins
- **Analytics**: Interactive scatter plots, bar charts, pie charts
- **Filtering**: Filter players by role and country

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Data

Sample cricket data for 15 international players including:
- Virat Kohli, Rohit Sharma, Babar Azam, Joe Root, Steve Smith
- Kane Williamson, David Warner, AB de Villiers, Chris Gayle
- Shakib Al Hasan, Ben Stokes, Ravichandran Ashwin, Pat Cummins, Jasprit Bumrah

And 10 cricket teams with their match statistics.
