# Cover Letter Generator

AI-powered tool to create compelling, personalized cover letters.

## Features
- Job description parsing
- Skills matching & highlighting
- Adjustable tone (Professional, Enthusiastic, Formal, Casual)
- Download as text file
- Professional formatting

## Setup
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_api_key
streamlit run app.py
```

## Usage
1. Enter your Gemini API key in the sidebar
2. Paste the job description
3. Describe your relevant skills and experience
4. Select your preferred tone
5. Generate and download your cover letter
