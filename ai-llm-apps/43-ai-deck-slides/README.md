# AI Deck Slides 📊

Generate professional PowerPoint slide content outlines for any presentation topic.

## Features

- **Professional Outlines** - Structured slides ready for your favorite tool
- **Customizable** - Adjust slide count, audience, and purpose
- **Visual Suggestions** - Includes recommended visuals per slide
- **Multiple Formats** - Business, training, pitch decks, and more

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your API key:
```bash
export GEMINI_API_KEY="your-api-key"
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Enter your presentation topic
2. Set the number of slides (5-20)
3. Select target audience and purpose
4. Choose optional features (data slides, Q&A)
5. Click "Generate Slides"
6. Get a complete slide outline with bullet points

## Example Topics

- Q4 Business Review
- Product Launch Announcement
- Annual Company Overview
- Training on New Software
- Investor Pitch

## Tech Stack

- Streamlit - Web UI
- Google Gemini - AI content generation
