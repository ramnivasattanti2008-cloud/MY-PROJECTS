# AI Caption Generator

Create viral-worthy captions for any image. Upload a photo or describe it, and get engaging captions for Instagram, Twitter, and more.

## Features

- Upload images or describe them
- Multiple caption styles (Casual, Professional, Inspirational, etc.)
- Platform-optimized captions with emojis and hashtags
- Generate 5 unique caption options

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your Gemini API key:
```bash
export GEMINI_API_KEY=your_api_key_here
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Upload an image OR describe what you see
2. Select your platform (Instagram, Twitter, Both)
3. Choose caption style
4. Click "Generate Captions"
5. Pick your favorite caption

## Caption Styles

- **Casual & Fun:** Relaxed, friendly tone
- **Professional:** Business-appropriate
- **Inspirational:** Motivational and uplifting
- **Humorous:** Witty and entertaining
- **Storytelling:** Narrative-driven

## Supported Platforms

- Instagram (with emojis + hashtags)
- Twitter/X (punchy, 280 chars max)
