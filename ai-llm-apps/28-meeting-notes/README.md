# Meeting Notes Organizer

Transform messy meeting notes or transcripts into structured, actionable summaries.

## Features
- Handles rough notes or full transcripts
- Extracts key discussion points
- Identifies decisions and action items
- Assigns owners to tasks
- Multiple output formats
- Export to markdown

## Setup
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_api_key
streamlit run app.py
```

## Usage
1. Enter your Gemini API key in the sidebar
2. Paste meeting notes or transcript
3. Select meeting type and format
4. Get organized summary with action items
5. Export for your records
