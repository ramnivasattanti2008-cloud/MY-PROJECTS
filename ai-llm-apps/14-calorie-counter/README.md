# 🍽️ AI Calorie Counter

Estimate calories in your meals and get healthier alternatives.

## Features

- Natural language meal input
- Calorie estimation
- Macronutrient breakdown
- Healthier alternatives
- Dietary preference support
- Quick add common foods

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)

3. Run the app:
```bash
streamlit run app.py
```

4. Enter your API key in the sidebar

## Usage

1. Describe your meal in natural language
2. Select dietary preference
3. Choose your health goal
4. Click "Analyze Meal"

## Sample Inputs

- "2 slices of pepperoni pizza with a beer"
- "Grilled chicken salad with ranch dressing"
- "Chicken biryani with raita"

## Disclaimer

This tool provides estimates only. For exact nutritional information, consult a registered dietitian or use official databases.
