# Trending Hashtag Generator

AI-powered hashtag suggestions for social media posts. Get trending and relevant hashtags tailored to your content and platform.

## Features

- AI-powered hashtag generation using Gemini
- Platform-specific optimization (Twitter, Instagram, LinkedIn)
- Dark theme with modern UI
- Quick copy-ready hashtags

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your Gemini API key:
```bash
export GEMINI_API_KEY=your_api_key_here
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Enter your tweet or social media post
2. Select your target platform
3. Click "Generate Hashtags"
4. Copy the trending hashtags

## Tech Stack

- Streamlit
- Google Gemini AI
- Python
