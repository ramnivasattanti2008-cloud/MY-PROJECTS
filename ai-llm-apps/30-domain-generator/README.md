# Domain Name Generator

AI-powered startup domain name brainstormer with availability hints.

## Features
- Industry-specific suggestions
- Multiple TLD options (.com, .io, .ai, .co, .app, .dev)
- Creative naming styles (Modern, Catchy, Descriptive, Invented, Playful)
- Meaning explanations for each name
- Availability hints
- Keyword integration

## Setup
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_api_key
streamlit run app.py
```

## Usage
1. Enter your Gemini API key in the sidebar
2. Describe your industry and business idea
3. Choose preferred TLD and style
4. Generate domain name suggestions
5. Check availability at your registrar

## Tip
Good domain names are memorable, easy to spell, and reflect your brand. Use suggestions as inspiration and combine with your own ideas.
