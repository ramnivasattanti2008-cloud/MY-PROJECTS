# Job Description Analyzer

Analyze job descriptions with AI to identify requirements and get resume improvement suggestions.

## Features

- Paste any job description
- Get key skills analysis (technical & soft skills)
- Understand experience level requirements
- Receive specific resume improvement tips
- Dark theme with polished UI

## Setup

1. Create a `.env` file with your API key:
```
GEMINI_API_KEY=your_api_key_here
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the app:
```bash
streamlit run app.py
```

## Usage

1. Paste a job description in the text area
2. Click "Analyze Requirements"
3. Get detailed analysis with skills, qualifications, and improvement tips

## Tech Stack

- Streamlit
- Google Gemini AI
- Python dotenv
