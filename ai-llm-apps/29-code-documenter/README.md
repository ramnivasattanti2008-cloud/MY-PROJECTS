# Code Documenter

AI-powered tool that generates comprehensive documentation for your code.

## Features
- Supports 9+ programming languages
- Multiple doc styles (Google, JSDoc, NumPy, Sphinx)
- Function/class documentation
- Parameter & return type docs
- Usage examples
- Complex logic explanations

## Setup
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_api_key
streamlit run app.py
```

## Usage
1. Enter your Gemini API key in the sidebar
2. Select the programming language
3. Choose documentation style
4. Paste your code
5. Generate and download documentation
