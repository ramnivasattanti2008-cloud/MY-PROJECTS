# Budget Planner

A Flask application to set monthly budgets and track expenses.

## Features

- Set monthly budgets
- Track expenses with categories
- Visual progress bar showing budget usage
- Category breakdown of expenses
- Budget alerts when exceeding 80% or 100%
- View expenses by month

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## How to Use

1. Set your monthly budget amount
2. Add expenses as you make them
3. Categorize expenses (Food, Transport, Entertainment, etc.)
4. Watch the progress bar to track spending
5. Get alerts when approaching or exceeding budget

## Categories

Expenses can be categorized as:
- Food
- Transport
- Entertainment
- Utilities
- Shopping
- Health
- Other
