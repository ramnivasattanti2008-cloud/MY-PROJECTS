# Link Aggregator

A simple Flask app to save and organize links with tags.

## Setup

```bash
cd flask-links
pip install -r requirements.txt
python app.py
```

Open http://localhost:5001

## Features

- Add, edit, delete links
- Tag-based organization
- Filter links by tag
- Search by URL, title, or description

## Database

SQLite (links.db) - auto-created on first run.
