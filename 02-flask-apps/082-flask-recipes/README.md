# Recipe Book

A Flask app to store and browse recipes with ingredients and instructions.

## Setup

```bash
cd flask-recipes
pip install -r requirements.txt
python app.py
```

Open http://localhost:5005

## Features

- Add recipes with name, description, prep/cook time, servings
- Store ingredients (one per line)
- Store step-by-step instructions
- Search recipes by name or description
- View full recipe details

## Database

SQLite (recipes.db) - auto-created on first run.
