# Contact Manager

A simple Flask application to store and manage your contacts.

## Features

- Store contacts with name, email, phone, and address
- Categorize contacts (Family, Friends, Work, Business, etc.)
- Search contacts by name, email, phone, or notes
- Filter by category
- View individual contact details

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## How to Use

1. Click "Add Contact" to save a new contact
2. Fill in the contact details (name is required)
3. Use the search bar to find contacts
4. Use the category dropdown to filter contacts
5. Click View, Edit, or Delete to manage contacts
