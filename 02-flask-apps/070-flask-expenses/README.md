# Expense Tracker

A Flask app to log expenses and view summaries by category.

## Setup

```bash
cd flask-expenses
pip install -r requirements.txt
python app.py
```

Open http://localhost:5004

## Features

- Log expenses with description, amount, category, and date
- View all-time total
- Category-wise breakdown
- Filter by month/year
- Delete expenses

## Database

SQLite (expenses.db) - auto-created on first run.
