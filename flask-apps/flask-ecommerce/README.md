# Flask E-Commerce

E-commerce starter with products, cart, and checkout flow.

## Setup

```bash
cd flask-ecommerce
pip install -r requirements.txt
python app.py
```

## Features

- Product catalog with images
- Shopping cart with add/remove
- Checkout flow (mock)
- Order confirmation
- Session-based cart storage

## Routes

- `/` - Product listing
- `/product/<id>` - Product detail
- `/cart` - Shopping cart
- `/checkout` - Checkout form
