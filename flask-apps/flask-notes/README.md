# Notes App

A Flask notes application with tags support using SQLite.

## Features

- Create, edit, and delete notes
- Add tags to organize notes
- Filter notes by tags
- SQLite persistence
- Clean, modern UI

## Setup

```bash
pip install -r requirements.txt
python app.py
```

## Run

Visit `http://localhost:5000`

The database file `notes.db` will be created automatically.
